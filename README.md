## 🚀 1. วิธีการนำไปใช้งาน (How to Run)

ระบบถูกออกแบบให้เป็น **Zero-Config Web Application** ไม่ต้องลงโปรแกรมหรือเซิร์ฟเวอร์ใดๆ ให้ยุ่งยาก สามารถเปิดใช้งานได้ทันที 2 รูปแบบ:

### รูปแบบที่ 1: ดับเบิลคลิกเปิดใช้งานทันที (แนะนำ)
1. เข้าไปที่โฟลเดอร์โครงการ:
   `D:\Users\chalit\.gemini\antigravity\scratch\asset-management-system`
2. ดับเบิลคลิกไฟล์ **`open-system.bat`** หรือดับเบิลคลิกไฟล์ **`index.html`**
3. ระบบจะเปิดขึ้นมาบน Google Chrome / Microsoft Edge พร้อมใช้งานได้ทันที 100%!

### รูปแบบที่ 2: เปิดผ่าน Local Web Server (เช่น Live Server หรือ Node.js / Nginx)
- หากใช้ **VS Code**: คลิกขวาที่ไฟล์ `public/index.html` แล้วเลือก **Open with Live Server**
- หรือนำโฟลเดอร์ `public` ไปวางบน Web Server ภายในบริษัท (เช่น Apache, IIS, Nginx) หรือ GitHub Pages เพื่อให้พนักงานในเครือข่ายเปิดใช้งานผ่าน URL ภายในบริษัทได้ทันที

## 💻 3. ฟังก์ชันการทำงานหลักของระบบ (Core Features)

### 3.1 แดชบอร์ดสรุปภาพรวมผู้บริหาร (Dashboard & Analytics)
- แสดงจำนวนทรัพย์สินรวม, ทรัพย์สินที่ใช้งานได้ปกติ, อุปกรณ์ที่ส่งซ่อม, อุปกรณ์สำรอง, และอุปกรณ์ที่ปลดระวาง/ชำรุด
- แสดงมูลค่าทรัพย์สินรวม (บาท)
- กราฟสัดส่วนหมวดหมู่ (Desktop PC vs Notebook vs Printer vs Server)
- กราฟสัดส่วนตามสถานะการใช้งาน
- กราฟ Bar Chart แผนกที่ครอบครองอุปกรณ์สูงสุด Top 8
- ฟีดแสดงรายการแจ้งซ่อมล่าสุด 5 รายการแบบเรียลไทม์

### 3.2 ระบบบริหารจัดการทะเบียนทรัพย์สิน (Asset Management)
- ค้นหาแบบทันที (Instant Live Search) จากรหัสทรัพย์สิน, ยี่ห้อ, รุ่น, Serial Number, ชื่อผู้ครอบครอง, จุดที่ตั้ง
- กรองข้อมูลตาม **แผนก (23 แผนก)**, **หมวดหมู่อุปกรณ์**, และ **สถานะ**
- ดูรายละเอียดเจาะลึก (Asset Detail Modal) แสดงรูปภาพจริงจาก Google Drive, สเปกคอมพิวเตอร์, และ **ประวัติการซ่อมทั้งหมดของเครื่องนั้น**
- เพิ่มทรัพย์สินใหม่ พร้อมระบบรัน ID ให้อัตโนมัติ (`ASTYYYYMMDDxxxxx`)
- แก้ไขข้อมูล หรือ ลบทรัพย์สิน (เฉพาะสิทธิ์ Admin)
- ปุ่มลัด **"แจ้งซ่อมอุปกรณ์นี้"** จากตารางได้ทันที
- ปุ่มสร้างและพิมพ์ **QR Code / ป้ายกำกับทรัพย์สิน** นำไปพิมพ์ติดตัวเครื่องได้ทันที

### 3.3 ระบบแจ้งซ่อมและประวัติงานซ่อมบำรุง (Maintenance & Repair Ticket)
- ระบบออกใบแจ้งซ่อมใหม่ (New Repair Ticket) พร้อมรหัสอัตโนมัติ `RP-YYYY-xxxx`
- มีระบบเลือกทรัพย์สินแบบค้นหาอัตโนมัติ เมื่อเลือกเครื่อง ระบบจะดึงรหัส แผนก และชื่อเครื่องมาลงฟอร์มให้ทันที
- **ระบบถ่ายภาพและอัปโหลดรูปภาพ 3 จุดสำคัญ**:
  1. **รูปอุปกรณ์ใหม่**: กดถ่ายรูป หรือเลือกไฟล์รูปเพื่อบันทึกรูปตัวเครื่อง
  2. **รูปก่อนซ่อม**: ผู้แจ้งสามารถกดปุ่ม "กดถ่ายรูปอาการเสีย" ผ่านกล้องมือถือ/เว็บแคม หรือเลือกรูปภาพอาการเสียแนบมากับใบแจ้งซ่อมได้ทันที
  3. **รูปหลังซ่อมเสร็จ**: ช่างผู้ซ่อมสามารถกดปุ่ม "กดถ่ายรูปผลงานหลังซ่อม" เพื่อยืนยันว่าเครื่องได้รับการแก้ไขเรียบร้อยแล้ว
  - มีระบบย่อขนาดและบีบอัดภาพอัตโนมัติ (Auto Image Compression) ช่วยประหยัดพื้นที่จัดเก็บและโหลดได้รวดเร็ว
- **ระบบเชื่อมโยงสถานะอัตโนมัติ (Status Auto-Sync)**:
  - เมื่อเปิดใบแจ้งซ่อม ทรัพย์สินชิ้นนั้นจะถูกเปลี่ยนสถานะเป็น **"ส่งซ่อม"** ทันที
  - เมื่อช่างทำการแก้ไขและเปลี่ยนสถานะเป็น **"ซ่อมเสร็จสิ้น (ปิดงาน)"** ระบบจะปรับสถานะทรัพย์สินกลับเป็น **"ใช้งานได้ปกติ"** ให้โดยอัตโนมัติ!
- บันทึกช่างผู้รับผิดชอบ, วันที่ดำเนินการ, วิธีการแก้ไข, อะไหล่ที่เปลี่ยน, และค่าใช้จ่าย
- **พิมพ์ใบแจ้งซ่อม A4 (Work Order Sheet)** พร้อมตารางข้อมูลและช่องลงนาม 3 ฝ่าย (ผู้แจ้งซ่อม, ช่างผู้ปฏิบัติงาน, ผู้ตรวจสอบ)

### 3.4 ระบบออกรีพอร์ตการแจ้งซ่อมขั้นสูง (Advanced Repair Reports)
แท็บ **"รายงานแจ้งซ่อม & ส่งออก"** ช่วยให้ผู้ดูแลระบบและผู้บริหารสามารถออกรายงานสรุปงานซ่อมบำรุงได้อย่างละเอียดและยืดหยุ่น:
- **เลือกรูปแบบระยะเวลาได้หลากหลาย**:
  - **ประจำเดือน (Monthly Report)**: เลือกเดือน (มกราคม - ธันวาคม) และปี พ.ศ./ค.ศ.
  - **ประจำปี (Annual Report)**: เลือกปี พ.ศ./ค.ศ. ที่ต้องการดูภาพรวมทั้งปี
  - **กำหนดช่วงวันที่เอง (Custom Date Range)**: ระบุตั้งแต่วันที่ ถึง วันที่ ได้อิสระ
  - **ข้อมูลทั้งหมด (All Time)**: ดูสรุปตั้งแต่เริ่มใช้งานระบบ
- **เลือกกรองตามแผนกของผู้แจ้งซ่อม (Department Filter)**: ดูเฉพาะแผนกที่ต้องการ เช่น แผนกซ่อมบำรุง, แผนกเทคโนโลยี, บุคคล, การเงิน, ผลิตโรงปลา ฯลฯ
- **กรองตามสถานะงานซ่อม**: ทุกสถานะ, รอดำเนินการ, กำลังดำเนินการ, ซ่อมเสร็จสิ้น
- **การประมวลผลและผลลัพธ์**:
  - การ์ดสรุป KPI ด้านบน: จำนวนงานซ่อมรวม, งานที่เสร็จแล้ว, งานค้างรอดำเนินการ, และรวมค่าใช้จ่ายการซ่อมบำรุง (บาท)
  - ตารางแจกแจงรายละเอียดทุกใบแจ้งซ่อม พร้อมชื่อผู้แจ้ง, อาการเสีย, ผลการซ่อม และช่างผู้รับผิดชอบ
  - **ปุ่ม "พิมพ์รายงานสรุป A4"**: ออกแบบฟอร์มเอกสารรายงานทางการ A4 สวยงาม พร้อมหัวกระดาษชื่อบริษัท และช่องลงนาม 3 ตำแหน่ง (ผู้จัดทำรายงาน, หัวหน้าแผนกสารสนเทศ, ผู้บริหาร/ผู้อนุมัติ)
  - **ปุ่ม "ส่งออก Excel (.xlsx)"**: นำข้อมูลที่ผ่านการกรองออกเป็นไฟล์ Excel ได้ทันที เพื่อนำไปทำ PivotTable หรือนำเสนอที่ประชุมต่อได้สะดวก

### 3.4 ระบบพิมพ์ป้ายสติกเกอร์ทรัพย์สินพร้อม QR Code (Asset Label Tag)
- แสดงชื่อบริษัท, รหัสทรัพย์สินตัวหนา, ชื่ออุปกรณ์, แผนก, Serial Number และชื่อผู้ครอบครอง
- สร้าง QR Code อัตโนมัติสำหรับสแกนตรวจสอบข้อมูลหน้าเครื่อง

### 3.5 ระบบจัดการแผนกและผู้ใช้งาน (Department & User Management)
- รองรับ 23 แผนกเดิมของบริษัท สามารถเพิ่ม แก้ไข และดูจำนวนเครื่องและประวัติการแจ้งซ่อมของแต่ละแผนกได้
- เพิ่ม/แก้ไข ผู้ใช้งานระบบ และกำหนดสิทธิ์ (Admin, Technician, User)

### 3.6 ระบบสำรองและส่งออกข้อมูล (Export & Backup)
- **ส่งออก Excel ทรัพย์สิน (.xlsx)**: ดาวน์โหลดไฟล์ Excel ข้อมูลทรัพย์สินทั้งหมด
- **ส่งออก Excel งานซ่อม (.xlsx)**: ดาวน์โหลดประวัติการแจ้งซ่อมทั้งหมดไปออกรายงาน
- **Full JSON Backup**: ดาวน์โหลดไฟล์สำรองข้อมูลทั้งหมดในคลิกเดียว
- **JSON Restore**: กู้คืนข้อมูลจากไฟล์สำรอง
- **Factory Reset**: ปุ่มคืนค่าระบบกลับเป็นข้อมูลเดิมตามไฟล์ Excel ของบริษัทได้ตลอดเวลา

## 🌐 6. วิธีการอัปโหลดขึ้น GitHub และเปิดใช้งานออนไลน์ฟรี (GitHub Pages)

ระบบนี้รองรับการนำขึ้น **GitHub** และสามารถเปิดเป็นเว็บแอปพลิเคชันออนไลน์ผ่าน **GitHub Pages** ให้ทุกคนในบริษัทหรือบุคคลที่เกี่ยวข้องเข้าใช้งานได้ผ่านสมาร์ตโฟน/คอมพิวเตอร์ได้ฟรีตลอด 24 ชั่วโมง โดยมีขั้นตอนง่ายๆ ดังนี้:

### ขั้นตอนที่ 1: สร้าง Repository ใหม่บน GitHub
1. เข้าไปที่ [github.com/new](https://github.com/new) และเข้าสู่ระบบบัญชีของคุณ (`flookoyza-star`)
2. ตั้งชื่อ Repository เช่น: `asset-management-system`
3. เลือกเป็น **Public** (หรือ Private ตามต้องการ)
4. **ไม่ต้อง** ติ๊กเลือก Add a README file (เพราะมีไฟล์อยู่แล้ว)
5. กดปุ่ม **"Create repository"**

### ขั้นตอนที่ 2: รันสคริปต์อัปโหลดขึ้น GitHub อัตโนมัติ (1-Click)
1. ไปที่โฟลเดอร์: `D:\Users\chalit\.gemini\antigravity\scratch\asset-management-system\`
2. ดับเบิลคลิกที่ไฟล์ **`upload-to-github.bat`**
3. โปรแกรมจะทำการรวบรวมไฟล์ทั้งหมด, ทำการ Commit และ Push ขึ้น Repository `https://github.com/flookoyza-star/asset-management-system.git` ให้โดยอัตโนมัติ

*(หรือหากต้องการรันคำสั่งด้วยตนเองผ่าน Terminal)*:
```bash
cd D:\Users\chalit\.gemini\antigravity\scratch\asset-management-system
git init -b main
git remote add origin https://github.com/flookoyza-star/asset-management-system.git
git add .
git commit -m "Initial commit - Asset & Maintenance Management System"
git push -u origin main
```

### ขั้นตอนที่ 3: เปิดใช้งานออนไลน์ฟรีผ่าน GitHub Pages
1. ไปที่หน้า Repository ของคุณบน GitHub: `https://github.com/flookoyza-star/asset-management-system`
2. คลิกแท็บ **"Settings"** (ขวาบน)
3. เมนูด้านซ้ายคลิกที่หัวข้อ **"Pages"**
4. ในส่วน **Branch** ให้เลือกเป็น `main` และเลือกโฟลเดอร์เป็น `/(root)` จากนั้นกดปุ่ม **Save**
5. รอระบบ GitHub ทำงานประมาณ 1 - 2 นาที จะได้รับลิงก์เว็บไซต์ออนไลน์ เช่น:
   👉 **`https://flookoyza-star.github.io/asset-management-system/`**
6. สามารถนำลิงก์นี้ไปส่งให้พนักงานในบริษัท หรือเปิดใช้งานผ่านมือถือ/แท็บเล็ตได้ทันทีทุกที่ทุกเวลา!
